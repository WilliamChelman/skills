# Write comments

- Do not state the obvious, let variable names and function names do that for you.
- No need to add comment if the code body is self-explanatory.
- Skip editorial comments. Don't explain why you did something, unless it is paramount to the understanding of the code or the choice would feel strange.
- Be concise and straight to the point. Sacrifice grammar for the sake of concision.
- Do not be influenced by established prose style. Follow these guidelines strictly.
